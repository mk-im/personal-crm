# groups Specification

## Purpose

Свои группы для людей, которых знаешь лично: у человека может быть несколько групп, на главной они стоят секциями, а заводят и правят группы на отдельной странице.

## Requirements

### Requirement: Groups page starts empty

The system SHALL открывать страницу «Группы» из шапки. Пока пользователь сам не создал группы, список групп MUST быть пустым: готовых групп «семья», «друзья», «знакомые», «теннис» и «аналитики» нет.

#### Scenario: No groups yet

- **WHEN** пользователь открывает страницу «Группы», и групп ещё нет
- **THEN** видно, что групп нет
- **AND** группу можно создать

#### Scenario: Open the page from the header

- **WHEN** пользователь нажимает «Группы» в шапке
- **THEN** открывается страница «Группы»

### Requirement: Create a group

The system SHALL создавать группу с страницы «Группы» по названию. Название MUST сохраняться без пробелов по краям.

#### Scenario: Create a group

- **WHEN** пользователь вводит «Теннис» и сохраняет
- **THEN** на странице «Группы» есть группа «Теннис»

#### Scenario: Trim the name

- **WHEN** пользователь сохраняет « Теннис »
- **THEN** группа называется «Теннис»

### Requirement: Reject an invalid group name

The system SHALL не создавать и не переименовывать группу, если название пустое, совпадает с уже существующим у этого пользователя без учёта регистра или равно «Без группы» без учёта регистра. Группа с тем же именем у другого пользователя MUST не мешать. The system MUST показать ошибку и оставить прежний список групп.

#### Scenario: Empty name

- **WHEN** пользователь сохраняет пустое название или одни пробелы
- **THEN** группа не появляется
- **AND** видна ошибка

#### Scenario: Duplicate name

- **WHEN** группа «Семья» уже есть у этого пользователя и он создаёт «семья»
- **THEN** второй группы нет
- **AND** видна ошибка

#### Scenario: Reserved name

- **WHEN** пользователь создаёт группу «без группы»
- **THEN** группы с таким названием нет
- **AND** видна ошибка

#### Scenario: Rename onto a taken name

- **WHEN** у этого пользователя есть «Семья» и «Теннис», и он переименовывает «Теннис» в «семья»
- **THEN** группа по-прежнему называется «Теннис»
- **AND** видна ошибка

#### Scenario: Same name for another user

- **WHEN** у другого пользователя уже есть группа «Семья» и текущий пользователь создаёт «Семья»
- **THEN** группа создаётся
- **AND** у другого пользователя его «Семья» остаётся

### Requirement: Rename a group

The system SHALL переименовывать группу со страницы «Группы». Люди остаются в этой группе. Заголовок секции на главной MUST показывать новое название.

#### Scenario: Rename a group

- **WHEN** пользователь переименовывает «Теннис» в «Корт»
- **THEN** на странице «Группы» и в секции на главной написано «Корт»
- **AND** в секции те же люди

### Requirement: Delete a group

The system SHALL спрашивать подтверждение перед удалением группы. После подтверждения группы MUST не быть, люди остаются в списке контактов, а членство в этой группе снимается. Без подтверждения группа и членство MUST остаться.

#### Scenario: Confirm delete

- **WHEN** пользователь подтверждает удаление «Теннис»
- **THEN** группы «Теннис» нет ни на странице «Группы», ни на главной
- **AND** люди этой группы остаются в списке контактов
- **AND** человек, у которого это была единственная группа, виден в секции «Без группы»

#### Scenario: Cancel delete

- **WHEN** пользователь начал удаление группы и не подтвердил
- **THEN** группа и её люди остаются как были

### Requirement: Assign existing groups on the contact

The system SHALL давать в формах создания и правки отметить уже созданные группы: несколько, одну или ни одной. Новую группу из формы контакта создать MUST быть нельзя. Если групп нет, контакт MUST всё равно сохраняться, а форма MUST вести на страницу «Группы».

#### Scenario: Several groups

- **WHEN** пользователь отмечает «Семья» и «Теннис» и сохраняет контакт
- **THEN** в карточке видны «Семья» и «Теннис»

#### Scenario: No group selected

- **WHEN** пользователь сохраняет контакт, не отметив ни одной группы
- **THEN** контакт сохранён
- **AND** в карточке у групп написано «не указано»

#### Scenario: No groups exist yet

- **WHEN** групп нет и пользователь открывает форму контакта
- **THEN** ввести новое название группы в форме нельзя
- **AND** из формы можно перейти на страницу «Группы»
- **AND** контакт можно сохранить

#### Scenario: Change the set of groups

- **WHEN** у контакта отмечена «Семья», пользователь снимает её, отмечает «Теннис» и сохраняет
- **THEN** в карточке виден «Теннис»
- **AND** «Семьи» у этого контакта нет

#### Scenario: Chosen group already deleted

- **WHEN** в форме ещё отмечена группа, которую уже удалили, и пользователь сохраняет контакт
- **THEN** изменения контакта не применяются
- **AND** видна ошибка

### Requirement: Home list is split into sections

The system SHALL делить список на главной на секции по группам. Секции групп MUST идти по алфавиту. Человек в нескольких группах MUST быть в каждой такой секции. Секция «Без группы» MUST быть последней и только если есть человек без групп. Группу без людей на главной показывать MUST NOT. Внутри секции люди MUST идти по имени.

#### Scenario: Alphabetical sections

- **WHEN** в «Теннис» и «Семья» есть люди
- **THEN** секция «Семья» выше секции «Теннис»

#### Scenario: Person in two sections

- **WHEN** человек входит в «Семья» и «Теннис»
- **THEN** он есть в обеих секциях

#### Scenario: Ungrouped section is last

- **WHEN** есть человек без групп и человек в «Семья»
- **THEN** секция «Без группы» ниже секции «Семья»

#### Scenario: Empty group stays off the home page

- **WHEN** в «Теннис» никого нет
- **THEN** на главной нет секции «Теннис»
- **AND** «Теннис» есть на странице «Группы»

#### Scenario: No ungrouped section

- **WHEN** у каждого контакта есть хотя бы одна группа
- **THEN** секции «Без группы» нет

#### Scenario: People inside a section by name

- **WHEN** в «Семья» есть «Борис» и «Анна»
- **THEN** «Анна» выше «Борис»

#### Scenario: No contacts at all

- **WHEN** контактов нет
- **THEN** на главной видно, что контактов нет
- **AND** секции «Без группы» нет

### Requirement: Group names on the row and the card

The system SHALL показывать все группы человека в строке списка и в карточке, по алфавиту. В строке внутри одной секции MUST быть видны и остальные группы этого человека. Если групп нет, строка списка MUST не показывать название группы, а карточка MUST показывать «не указано».

#### Scenario: Both names on the row and the card

- **WHEN** человек входит в «Теннис» и «Семья»
- **THEN** в строке списка и в карточке видны «Семья» и «Теннис»
- **AND** «Семья» раньше «Теннис»

#### Scenario: Row inside one section still shows the other group

- **WHEN** человек входит в «Семья» и «Теннис» и смотрит его строку в секции «Семья»
- **THEN** в этой строке видны и «Семья», и «Теннис»

#### Scenario: Person without groups

- **WHEN** у человека нет групп
- **THEN** в строке списка нет названия группы
- **AND** в карточке у групп написано «не указано»

### Requirement: Search and the count are about people

The system SHALL по поиску имени оставлять только найденных людей и строить секции из них. «Всего» и «Нашли» MUST считать людей, а не строки секций. Блок «Пора связаться» MUST оставаться над списком, не делиться на группы и MUST скрываться во время поиска, как и раньше.

#### Scenario: Search keeps one section

- **WHEN** поиск по имени находит одного человека из «Семья»
- **THEN** в списке только он, в секции «Семья»
- **AND** счётчик равен 1

#### Scenario: Two sections still count as one person

- **WHEN** в списке один человек, и он в двух группах
- **THEN** он виден в двух секциях
- **AND** счётчик равен 1

#### Scenario: Due block stays whole

- **WHEN** на главной без поиска есть с кем пора связаться
- **THEN** блок «Пора связаться» один и стоит над секциями

#### Scenario: Due block hides during search

- **WHEN** пользователь ищет по имени
- **THEN** блока «Пора связаться» нет

### Requirement: Deleting a contact leaves the groups

The system SHALL при удалении контакта убирать его из всех групп. Сами группы MUST остаться.

#### Scenario: Contact deleted, group remains

- **WHEN** пользователь удаляет контакт, который был в «Теннис»
- **THEN** этого контакта нет в секциях
- **AND** группа «Теннис» остаётся на странице «Группы»
