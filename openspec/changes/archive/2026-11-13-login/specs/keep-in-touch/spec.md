# Spec Delta

## MODIFIED Requirements

### Requirement: Due block on the home page

The system SHALL показывать на главной блок «Пора связаться» над списком контактов, если у вошедшего пользователя есть хотя бы один просроченный контакт. Чужой просроченный контакт MUST не показывать этот блок. The system SHALL скрывать блок, если просроченных нет, и SHALL скрывать его во время поиска по имени.

#### Scenario: Someone is due

- **WHEN** на главной без поиска у вошедшего пользователя есть просроченные контакты
- **THEN** над списком виден блок «Пора связаться»

#### Scenario: Nobody is due

- **WHEN** у вошедшего пользователя просроченных контактов нет
- **THEN** блока «Пора связаться» нет

#### Scenario: Searching hides the block

- **WHEN** пользователь ищет контакты по имени
- **THEN** блока «Пора связаться» нет

#### Scenario: Another user's overdue contact stays hidden

- **WHEN** у другого пользователя есть просроченный контакт, а у вошедшего просроченных нет
- **THEN** блока «Пора связаться» нет
