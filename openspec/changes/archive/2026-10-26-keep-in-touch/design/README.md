# Макеты keep-in-touch

Эталоны экранов фичи. Цвета и шрифт — из `src/styles/tokens.css` приложения.

| Файл | Ширина |
|---|---|
| `mobile.html` | 390 px |
| `desktop.html` | 1440 px |

Экраны в каждом файле сверху вниз:

1. Главная с блоком «Пора связаться»
2. Главная во время поиска — блока нет
3. Карточка с заданной частотой
4. Форма «Изменить» с полем частоты
5. Карточка без частоты

Тексты в макете — примеры. Подпись поля «Как часто общаться» в требованиях не зафиксирована.
