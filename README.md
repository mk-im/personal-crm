# Личная CRM

Список людей, которых знаете лично: кто это, откуда знакомы, телефон, почта и о чём договорились. К карточке можно дописать заметку после разговора.

Живое приложение: [app.црм.space](https://app.црм.space). Лендинг: [црм.space](https://црм.space).

## Как запустить

1. Запустите Docker Desktop.
2. В папке проекта выполните `docker compose up -d` — поднимется PostgreSQL.
3. `pnpm install`
4. `pnpm db:migrate`
5. `pnpm db:seed` — добавит 1000 тестовых контактов, если база ещё пустая.
6. `pnpm dev` и откройте http://localhost:3000

Строка подключения к базе лежит в `.env`.

## Как выкатывается на сервер

Пуш в ветку `main` собирает образ, кладёт его в GitHub, затем на сервере применяет миграции и поднимает новую версию. Если миграции или проверка `/health` не прошли, старое приложение не меняется.

Чтобы выкатить новую версию, закоммитьте изменения и отправьте их в `main`.
